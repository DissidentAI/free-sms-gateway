# Contributing

Thanks for considering a contribution!

1. Discuss major changes in an issue before opening a large pull request.
2. Make changes on a feature branch and add tests for behavior changes.
3. Run `python3 -m pip install -r requirements-dev.txt` and `python3 -m pytest -q`.
4. Keep documentation clear and examples anonymous. Never commit real phone numbers, credentials, logs or private account data.
5. Ensure pull requests describe the problem, the change and any security implications.

Please follow the [Security policy](SECURITY.md) to report vulnerabilities privately.
